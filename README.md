# SaluteDevHelper 📺⚡

> Легковесное Android TV приложение для быстрого доступа к скрытым системным параметрам разработчика, инспекции сети и упрощения отладки на телевизорах **SaluteTV (SberOS / StarOS)** на базе SoC **MediaTek MT9632 / m7332**.

---

## 🎯 Назначение

На телевизорах под управлением SberOS / SaluteTV интерфейс «Для разработчиков» намеренно скрыт из стандартного меню, а диалог авторизации отладки по USB (`UsbDebuggingActivity`) часто не отображается поверх лаунчера.

**SaluteDevHelper решает эту проблему в 1 клик:**
1. **Мгновенный запуск скрытых настроек**: При старте приложение автоматически инициирует скрытую системную активность параметров разработчика Android TV (`com.android.tv.settings/.system.development.DevelopmentActivity`).
2. **Dashboard для ПК**: На экране телевизора крупным шрифтом выводятся:
   * Текущий локальный IP-адрес ТВ в сети Wi-Fi/Ethernet.
   * Готовая строка подключения ADB: `adb connect <IP>:5555`.
   * Готовая строка подключения SSH: `ssh admin@<IP> -p 2222`.
   * Статус доступности локальных портов: **ADB (5555)** и **SSH (2222)**.
3. **Управление с пульта**: Удобный темный интерфейс (Modern Dark Slate + Cyan/Green), оптимизированный для телевизоров, пультов ДУ и D-pad навигации.

---

## 🛠 Архитектура и стек

* **Платформа**: Android TV / Leanback (Android 9.0+ / API 28–34).
* **Архитектура SoC**: Универсальная (Java/D8 DEX bytecode, без тяжелых нативных библиотек).
* **Размер APK**: всего **~26 КБ** (максимально быстро ставится и не занимает драгоценную память устройства).
* **Зависимости**: Чистый Android SDK без раздутых сторонних фреймворков.

---

## 🚀 Установка

1. Скопируйте файл `SaluteDevHelper.apk` на USB-флешку.
2. Вставьте флешку в телевизор и установите приложение через любой доступный файловый менеджер на ТВ.
3. Откройте приложение:
   * Оно попытается сразу вывести окно параметров разработчика.
   * Включите тумблер **«Отладка по USB»**.
   * На экране приложения посмотрите ваш локальный IP и выполните подключение с компьютера:
     ```bash
     adb connect <IP>:5555
     ```
